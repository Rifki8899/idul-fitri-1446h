# 🌙 Ucapan Selamat Idul Fitri 1446 H

> **[🔗 Buka di Browser →](https://YOUR_USERNAME.github.io/idul-fitri-1446h)**

Kartu ucapan Hari Raya Idul Fitri interaktif dengan musik Islami generatif, animasi masjid, dan fitur share ke WhatsApp & Instagram.

---

## ✨ Fitur

- **🎵 3 Track Musik Islami** — dibuat langsung di browser (Web Audio API), tanpa file eksternal:
  - 🎸 **Oud & Strings** — melodi Maqam Hijaz dengan plucked oud + string pad
  - 🥁 **Rebana & Qasida** — pola rebana (dum-tek-ka) + melodi Maqam Rast
  - 🌊 **Ambient Ramadhan** — lush chords + bell tones + ney flute + angin

- **🕌 Ilustrasi Masjid SVG** — animasi lentera, bulan mengambang, bintang berkedip

- **✏️ Personalisasi Real-time** — nama, penerima, pesan tambahan, tema warna

- **💥 Confetti Burst** — ketuk masjid untuk merayakan!

- **📤 Share** — WhatsApp, Instagram, Salin Link, Salin Teks
